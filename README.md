# nailkatuha

Сайт студии маникюра и nail art в Санкт-Петербурге: запись по свободным окошкам, работы
мастера с фильтрами по длине и стилю, примерка дизайна на свои руки через камеру.
Фронтенд на Next.js 16, сервер записи на Go.

**Демо:** https://youngover.github.io/nailkatuha/

## Что внутри

| | |
|---|---|
| Типсы в герое | Настоящие 3D-ногти: сетка с поперечным изгибом как у живого ногтя, физический лаковый материал с прозрачным топом, студийный свет из светящихся панелей без HDR-файлов. Можно выбрать цвет, форму (миндаль, квадрат, балерина, стилет) и покрытие. «Кошачий глаз»: полоса блёсток ходит за курсором, как магнитный гель за магнитом. При смене цвета лак «наносится» от кутикулы к краю |
| Отдельный поток для 3D | Вся сцена работает в Web Worker на OffscreenCanvas: разбор three.js, сборка шейдеров и кадры не трогают основной поток, прокрутка и клики не подтормаживают. Без OffscreenCanvas сцена запускается на странице |
| Курсор-пилочка | Кончик пилки точно под указателем, без задержки; наклон зависит от скорости; над кнопками пилит, оставляя пыль и звук. Только на устройствах с мышью |
| Лак на весь сайт | 8 оттенков из мудбордов мастера красят и типсы, и акценты сайта. Смена расходится каплей от точки клика через View Transitions API, выбор переживает перезагрузку без мигания |
| Звук | Пилка, крышка флакона и UV-лампа синтезируются Web Audio на лету, без файлов. По умолчанию выключен |
| Работы | Маска карточки повторяет длину ногтей на фото: от мягкого квадрата до стилета. Просмотр в нативном `<dialog>` с переходом из миниатюры, стрелками, свайпом и возвратом фокуса |
| Пять причин | Каждая причина подтверждена работой мастера: наводите на строку, рядом появляется фото |
| Цены | Меню с точечными выносками; строка ведёт к записи на эту услугу. Цены и адрес в HTML и в разметке `schema.org/BeautySalon` |

## Адаптивность

Каждая сборка снимается на 7 размерах: 360×780, 390×844, 844×390 (телефон боком),
768×1024, 1024×768, 1440×900, 2560×1440. Скрипт падает, если появилась горизонтальная
прокрутка или ошибка в консоли. Отдельный сценарий проверяет взаимодействия:

- просмотр фото;
- фильтры;
- мобильное меню, которое закрывается после выбора раздела;
- сохранение лака;
- отсутствие курсора-пилочки на тач-экранах.

```sh
cd web
npm ci
npm test            # логика: цены, маски, палитра и контраст текста на каждом лаке
npm run build       # статическая сборка в out/
npm run shots       # скриншоты 7 размеров в docs/shots
npm run e2e         # сценарии взаимодействия в Chrome
node scripts/perf.mjs  # кадры, длинные задачи, пересчёты раскладки на реальной видеокарте
```

## Сервер

`server/` на Go 1.25. Сейчас отдаёт каталог услуг; в работе запись с живыми окнами,
удержанием окна на 5 минут и защитой от двойной записи на уровне PostgreSQL.

```sh
cd server
go test ./...
go run ./cmd/nailkatuha -addr :8080   # GET /api/services, GET /healthz
```

## Раскладка

```
web/src/app        страницы: главная и портфолио
web/src/sections   секции главной
web/src/components кнопки, просмотр фото, фильтры, карта
web/src/fx         3D-типсы (сцена, воркер, геометрия ногтя, лаковый материал), курсор-пилочка, лак, звук
web/src/content    тексты, цены, фото с тегами, формы ногтей
server/            сервер записи на Go
```
